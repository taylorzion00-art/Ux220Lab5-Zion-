Lab 5: Custom Elements

This page uses two custom elements I made with JavaScript. <x-center> centers whatever goes inside it in a styled box, and <x-grade> turns an experience and a letter grade into a card. The cards below are the five experiences from my Looking Back assignment.

 Beating a playoff team that had already beaten us earlier in the season. Worth every cold practice. Free food and taste-testing new recipes were great. The supervisor was not. My friend got us caught five times in a row. We never finished, but we couldn't stop laughing. Paid for things I didn't need and never got on a single ride. Debugging is rough, but seeing something I built actually work makes it worth it.

How it works

Each custom element is a class that extends HTMLElement. When the browser finds the tag on the page, connectedCallback runs. It puts inline styles on the element and replaces its innerHTML with new markup. customElements.define() connects the tag name to the class. Custom element names need a dash in them, which is why these are called x-center and x-grade.
